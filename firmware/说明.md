# firmware 目录说明

| 文件 | 是什么 | 该刷哪个 |
|---|---|---|
| **opendm40-v0.4.0-zh.bin** | **本项目的汉化版**（632,576 字节） | ✅ **就刷这个** |
| opendm40-v0.3.0-zh.bin | 旧的 v0.3.0 汉化版（仅存档） | 只有想回退到旧版才用 |
| opendm40-v0.3.0-official.bin | 上游 opendm40 v0.3.0 原版（英文界面） | 想对比 / 回退到英文版时用 |
| dm40_v_2_6-stock.bin | 原厂 V2.6 固件备份（刷回出厂时用） | 只在回退原厂时用 |
| link-native.x | 链接脚本（构建用，不是固件） | 不要刷 |

刷机方法见 README 顶部「刷机（推荐：直接复制文件）」。
刷错文件不会变砖：表会先校验，不合格直接拒绝并弹「不是 DM40 升级文件」。
