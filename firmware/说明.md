# firmware 目录说明

| 文件 | 是什么 | 该刷哪个 |
|---|---|---|
| **DM40_v0.4.1.01.BIN** | **本项目的汉化版**（634,624 字节，CRC-32 `76abcf09`，含 Snail 开机字标）；文件名本来就是表要的 `DM40*.BIN`，拷到 U 盘根目录即可，不用改名 | ✅ **就刷这个** |
| opendm40-v0.4.1-official.bin | 上游 opendm40 v0.4.1 原版（英文界面，与汉化版同源同工具链） | 想对比 / 回退英文版时用 |
| opendm40-v0.4.0-zh.bin | 旧的 v0.4.0 汉化版（zh10，仅存档） | 只有想回退上一版才用 |
| opendm40-v0.3.0-zh.bin | 旧的 v0.3.0 汉化版（仅存档） | 只有想回退到旧版才用 |
| opendm40-v0.3.0-official.bin | 上游 opendm40 v0.3.0 原版（英文界面） | 想对比 / 回退到英文版时用 |
| dm40_v_2_6-stock.bin | 原厂 V2.6 固件备份（刷回出厂时用） | 只在回退原厂时用 |
| link-native.x | 链接脚本（构建用，不是固件） | 不要刷 |

## v0.4.1.01 与上游 v0.4.1 的差别

- 界面中文（措辞与 v0.4.0-zh10 一致），汉字统一 16 px（宋体渲染，353 字，含全角标点）。
- 版本串为 `0.4.1.01`（设备信息页 / `*IDN?` / 记录表头 / 开机画面）。
- 设备信息页的厂商行显示「正点原子 & 蜗牛」（`patch/v041/vendor_name.py`）。
- 开机画面：**Snail** 字标（134×47 单色位图，799 字节，画在 A2 区）居中在
  「opendm40 / v0.4.1.01 / 载入中... / 进度条」上方，整块在屏幕上垂直居中（上下各 66 px）。
- 区域余量：A2 区 1,524 字节、B 区 4,224 字节、C 区 4,384 字节（构建时实测，见 `docs/刷机与构建记录.md`）。

刷机方法见 README 顶部「刷机（推荐：直接复制文件）」。
刷错文件不会变砖：表会先校验，不合格直接拒绝并弹「不是 DM40 升级文件」。
